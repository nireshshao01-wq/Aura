Drop your photos in this folder. The site finds them automatically, no code changes needed.

Name each file after what it shows (jpg, jpeg, png, webp or avif):

  Product photos      c1.jpg  c2.jpg ... j1.jpg ... g1.jpg ... s1.jpg ... sc1.jpg ... k1.jpg ... a1.jpg ... h1.jpg
                      (the product ids are listed in core.js, for example h1 = Ribbed Ceramic Vase)
  Home page banner    hero.jpg           (portrait works best, about 4:5)
  Category tiles      cat-clothing.jpg, cat-jewellery.jpg, cat-gifting.jpg, cat-cushions.jpg,
                      cat-sculptures.jpg, cat-kitchen.jpg, cat-accessories.jpg, cat-decor.jpg
  Gifting banner      gift-band.jpg

Extra photos for the same product (a gallery on the product page): add -2, -3, -4 ... to the name, for example c1.jpg (cover), c1-2.jpg, c1-3.jpg.

Square product photos on a clean background look best, around 1200 x 1200 px and under 300 KB each.
Only use photos you own, have bought, or have written permission to use.
